# ACL Hunt Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a Linux-native Hunt mode that identifies SCCM content blobs referenced by inaccessible DataLib entries and downloads the matching FileLib blobs.

**Architecture:** Preserve go-cmloot's single-binary design and reuse its authenticated SMB connection. Inventory records access-denied DataLib paths to a companion no-access file. Hunt reads that file, examines FileLib metadata, and saves matched blobs with an auditable manifest.

**Tech Stack:** Go 1.19, github.com/jfjallid/go-smb, Go standard library.
